# Classroom Roster App

A classroom management app built for an elementary school teacher — roster
and attendance, behavior tracking, homework and grading, group building,
seating charts, event and field trip tracking, skills mastery tracking,
pacing guide, and parent communication tools, all in one place.

## Features

- **Dashboard** — daily overview: today's pacing, attendance, homework flags, upcoming events
- **Roster & Attendance** — daily tracking, CSV import/export, print view
- **Behavior & Contact Log** — incident tracking with a parent contact log and weekly outreach goal tracker
- **Homework & Assignments** — status tracking, grading, late-penalty support, grade histograms
- **Gradebook** — per-category grades with an overall summary
- **Group Builder** — automatic grouping with conflict avoidance
- **Seating Chart** — multiple layout templates, conflict-aware
- **Skills Tracker** — customizable subject/skill mastery tracking with visual progress
- **Pacing Guide** — unit and topic planning with automatic schedule tracking
- **Events Tracker** — field trips and events, payment tracking, chaperone signups
- **School Calendar** — days off, half days, and work days
- **Daily Schedule** — a unified view of the day's bell schedule
- **Newsletter** — a running weekly note that goes out with parent reports
- **Weekly Report** — a ready-to-send Friday parent update
- **Sub Mode** — a printable substitute-day packet with only what a substitute needs to know
- **Student Profiles** — a single view of everything about a student, safety info flagged clearly
- **Multi-classroom support** — for teachers with more than one class or Period
- **Role-based accounts** — separate Teacher, Principal, and Admin access levels

No student photos are stored, by design.
